# NexaFlow Website Publish Checklist

Use this before putting the site online.

## 1. Replace Contact Details

Open `script.js` and change:

```js
contactEmail: "shekinahleope24@gmail.com",
whatsappNumber: "27680771654",
whatsappDisplay: "+27 68 077 1654",
```

to your preferred business contact details.

Also update the structured data email and telephone in `index.html` if you change them.

## 2. Confirm The Business Name

Current name:

```text
NexaFlow AI Studio
```

Keep it if you like it. If not, ask Codex to rename the site everywhere.

## 3. Current Public URL

Until a custom domain is connected, the GitHub Pages URL should be:

```text
https://fxlegend-dev.github.io/nexaflowstudios/
```

## 4. Choose A Custom Domain Later

Good domain examples:

```text
nexaflowai.com
nexaflowstudio.com
nexaflowautomation.com
```

Avoid domains that make the business sound unrelated, overly corporate, or confusing. For example, `nexaflowmeter.com` does not fit an AI services studio well.

Before buying, search the name and domain to avoid obvious conflicts.

## 5. Publish With Netlify

Beginner-friendly path:

1. Go to Netlify.
2. Create an account.
3. Drag the whole `website` folder into Netlify Drop.
4. Netlify gives you a public URL.
5. Later, connect your custom domain.

## 6. Publish With GitHub Pages

Alternative path:

1. Put the project in a GitHub repository.
2. Go to repository Settings.
3. Open Pages.
4. Choose the branch and folder.
5. Save and wait for the public URL.

## 7. Final Checks

- Open the site on desktop.
- Open the site on mobile.
- Click every navigation link.
- Submit a test contact form.
- Confirm the email opens correctly.
- Check spelling.
- Make sure the offer is clear.
- Make sure the first call to action is easy to find.

## 8. Next Business Asset

After publishing, create a demo:

```text
AI lead response system for a fitness coach
```

That gives you something concrete to show prospects.
